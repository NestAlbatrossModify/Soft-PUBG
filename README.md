# Soft PUBG

Download: soon

Legit-style soft aim for PUBG. Meant to look human on killcams.

The aim moves with a slow smoothing curve, small FOV, visible targets only, no snapping. Bone priority defaults to chest, switchable to head for close fights.

- profile per weapon class
- aim key hold-only by default
- optional FOV circle for tuning

Windows 10/11, Steam, administrator. Tested with 1000+ hours of normal play style.
